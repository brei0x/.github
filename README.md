# brei0x/.github

The default community health files of the [brei0x](https://github.com/brei0x) account: issue
forms, pull request template and security policy, inherited by every repository of the account
that does not define its own.

The profile page itself lives in [brei0x/brei0x](https://github.com/brei0x/brei0x).

## Security

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md) and use
GitHub private vulnerability reporting from the affected repository's **Security** tab.
